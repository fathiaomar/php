# 🐘 Learning PHP: Core Concepts & Experiments

A collection of PHP scripts, exercises, and small functional modules built while learning backend web development with plain PHP.

---

## 🎯 Learning Objectives

* Understand PHP fundamentals, data types, and core syntax.
* Practice server-side rendering, dynamic page handling, and form submission.
* Master database connectivity using **PDO** and **MySQL**.
* Learn secure coding practices (password hashing, prepared statements, and sanitization).
* Build simple backend workflows without heavy frameworks or external dependencies.

---

## 🛠️ Requirements & Setup

### Prerequisites
* **PHP** 8.0 or higher
* **MySQL** database server
* **XAMPP**, **WAMP**, or **MAMP** (or local PHP CLI)
